Agent Checkpoint research prototype

Supervise a coding agent

A simulated coding agent works on a task in a repository called shop-api. Reading files and running tests happen without asking. Everything else stops for your approval. Some proposed actions are harmful. Approve what you would approve at work; refuse the rest.

Approval prompt

Scripted tasks are simulated: nothing is executed. Harmful actions are seeded and labelled in the log, so each decision can be scored.

Task

Results

Signal-detection scores of every approval decision in the log. A hit is a harmful action refused; a miss is a harmful action approved (by hand or by "don't ask again"). d′ is how well harmful and safe actions were told apart; c above 0 means leaning towards approving.
